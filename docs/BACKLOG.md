# 📝 Бэклог и Идеи (На будущее)

В этот файл мы будем записывать все крутые идеи, доработки и "хотелки", которые всплывают в процессе разработки, но не блокируют текущую фазу. Когда основные фичи по `ROADMAP.md` будут готовы, мы вернемся сюда.

## Отложенные задачи:
- [ ] **AI-Powered Universal Ingestion:** Уход от хардкодных парсеров. Использование LLM для автоматического определения структуры любого банковского файла (Excel/CSV) и маппинга колонок.
- [ ] **Multi-Family / Shared Budget Support:** Внедрение `family_id` в базу. Возможность объединять нескольких пользователей (муж, жена, родственники) в одну "семью" для ведения общего бюджета.
    - *Дополнение:* В истории (`/history`) добавить фильтры по членам семьи (кнопки `[Все]`, `[Мои]`, `[Имя]`), чтобы можно было смотреть как общий поток трат, так и индивидуальный.
- [ ] **Меню Настройки профиля:** Сделать полноценное меню настроек, где пользователь сможет жестко задать язык интерфейса (не полагаясь на `language_code` из Телеграма), а также в будущем выбирать визуальные темы, цвета графиков и другие персонализации.
- [ ] **Fuzzy Search для Алиасов:** Если пользователь пишет счет с сильной опечаткой, можно сделать быстрый локальный fuzzy-поиск (например, через `difflib`) перед тем, как отправлять запрос в LLM. Это сэкономит время и деньги на API.
- [ ] **Настройка полноценного логирования:** Сейчас ошибки просто пишутся в консоль (stdout). Необходимо настроить запись логов в файл с ротацией (например, через `logging.handlers.RotatingFileHandler`), чтобы мы могли анализировать ошибки постфактум, не теряя историю при перезапуске контейнера или процесса.
- [ ] **Telegram Mini App (TMA) Dashboard:** Создание интерактивного веб-интерфейса прямо внутри Telegram. Это позволит реализовать динамические графики (Plotly/Chart.js) с фильтрами, удобное управление категориями и наглядные дашборды для всей семьи.
- [ ] **Проактивный AI-советник:** Фоновая задача, которая раз в неделю/месяц анализирует траты, выявляет аномалии ("Траты на транспорт выросли на 30%") и дает советы по оптимизации бюджета.
- [ ] **Interactive Rule Learning:** Реализовать через бота механизм обучения: когда пользователь вручную выбирает категорию для новой транзакции, бот предлагает "запомнить это правило навсегда" для этой семьи (автоматическое создание записи в `item_aliases`).
- [ ] **Управление счетами и картами через Telegram (Личный кабинет):** Возможность добавлять, редактировать и перевыпускать карты напрямую через интерфейс бота (без лазания в базу данных).
    - *Суть:* Когда у пользователя меняется карта (например, с `4787` на `9999`), он заходит в «Настройки/Личный кабинет», выбирает свой счет («Андрей») и добавляет к нему новую маску карты. При этом вся история транзакций по старой маске сохраняется, так как физические номера карт (`account_aliases`) и вечные логические счета (`accounts`) полностью отделены друг от друга.
- [ ] **Кнопки управления семьей (Личный кабинет Администратора):** Реализовать в боте для Администратора (`is_admin = true`) интерфейс/меню управления: «Добавить участника», «Добавить карту», «Перевыпустить карту» и т.д.
