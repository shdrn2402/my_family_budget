# План разработки: My Family Budget Bot (AI Engineer Edition)

Этот документ описывает поэтапный план реализации финансового агента. Проект фокусируется на интеграции современных паттернов ИИ (NLP, NL2SQL, Vision, MCP) для создания интеллектуального помощника и сильного портфолио AI-инженера.

## Фаза 1: Базовый фундамент и Smart Data Entry (MVP)
*Цель: Заложить архитектуру проекта и реализовать "умный" ввод данных через LLM вместо классических регулярок.*
- [x] Настройка базы данных и привязка пользователей (`user_id`).
- [x] **Fast Data Entry (MVP):** Реализация сверхбыстрого парсера по формату "товар счет сумма" с использованием базы синонимов.
- [x] Сохранение структурированных транзакций в PostgreSQL.
- [x] Интеграция с LLM (через API или локальную модель).
- [x] **NLP Data Entry (Function Calling):** Обработка естественного свободного текста (например, "вчера отдал 500 за кофе и 2к за бензин") — извлечение сущностей через LLM и маппинг.
- [x] Базовая команда `/history` для проверки корректности распознавания.

## Фаза 2: Удобство управления и Мультимодальный ввод (Завершено ✅)
*Цель: Расширить каналы ввода и добавить удобный интерфейс редактирования.*
- [x] **Voice-to-Text:** Обработка голосовых сообщений (через Whisper/Gemini) с последующей маршрутизацией в пайплайн из Фазы 1.
- [x] Инлайн-меню после добавления: кнопки `[Изменить категорию]` и `[Удалить]`.
- [x] Интерактивная история: инлайн-пагинация и управление записями.
- [x] Парсинг выписок (Excel/XLSX) с автоматической дедупликацией и массовой категоризацией.

## Фаза 3: Chat with Data (Аналитика через NL2SQL) [DONE]
*Цель: Заменить скучные кнопки статистики на полноценное общение с данными.*
- [x] **Text-to-SQL Пайплайн:** Перевод вопросов пользователя ("Сколько мы потратили на еду в этом месяце?") в безопасные SQL-запросы.
- [x] Исполнение запросов в БД и генерация сводного текстового ответа через LLM.
- [x] Генерация графиков: по результатам SQL-выборки бот строит графики (Pie/Bar chart) и отправляет их картинкой.
