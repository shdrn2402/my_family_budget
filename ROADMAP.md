# План разработки: My Family Budget Bot (AI Engineer Edition)

Этот документ описывает поэтапный план реализации финансового агента. Проект фокусируется на интеграции современных паттернов ИИ (NLP, NL2SQL, Vision, MCP) для создания интеллектуального помощника и сильного портфолио AI-инженера.

## Фаза 1: Базовый фундамент и Smart Data Entry (MVP)
*Цель: Заложить архитектуру проекта и реализовать "умный" ввод данных через LLM вместо классических регулярок.*
- [x] Настройка базы данных и привязка пользователей (`user_id`).
- [x] **Fast Data Entry (MVP):** Реализация сверхбыстрого парсера по формату "товар счет сумма" с использованием базы синонимов.
- [x] Сохранение структурированных транзакций в PostgreSQL.
- [x] Интеграция с LLM (через API или локальную модель).
- [x] **NLP Data Entry (Function Calling):** Обработка естественного свободного текста (например, "вчера отдал 500 за кофе и 2к за бензин") — извлечение сущностей через LLM и маппинг.
- [ ] Базовая команда `/history` для проверки корректности распознавания.

## Фаза 2: Удобство управления и Мультимодальный ввод
*Цель: Расширить каналы ввода и добавить удобный интерфейс редактирования.*
- [ ] **Voice-to-Text:** Обработка голосовых сообщений (через Whisper) с последующей маршрутизацией в пайплайн из Фазы 1.
- [ ] Инлайн-меню после добавления: кнопки `[Изменить категорию]`, `[Изменить сумму]`, `[Удалить]`.
- [ ] Интерактивная история: инлайн-пагинация и управление записями.
- [ ] Парсинг выписок (CSV/PDF) с защитой от задвоения с ручным вводом.

## Фаза 3: Chat with Data (Аналитика через NL2SQL)
*Цель: Заменить скучные кнопки статистики на полноценное общение с данными.*
- [ ] **Text-to-SQL Пайплайн:** Перевод вопросов пользователя ("Сколько мы потратили на еду в этом месяце?") в безопасные SQL-запросы.
- [ ] Исполнение запросов в БД и генерация сводного текстового ответа через LLM.
- [ ] Генерация графиков: по результатам SQL-выборки бот строит графики (Pie/Bar chart) и отправляет их картинкой.
- [ ] **Проактивный AI-советник:** Фоновая задача, которая раз в неделю/месяц анализирует траты, выявляет аномалии ("Траты на транспорт выросли на 30%") и дает советы.

## Фаза 4: Vision AI и Интеграция (MCP)
*Цель: Внедрение продвинутого компьютерного зрения и стандартов индустрии.*
- [ ] **Smart Receipt OCR (Vision AI):** Обработка фотографий длинных чеков. Мультимодальная модель распознает позиции, понимает скидки и разбивает один чек на разные категории (еда, хозтовары).
- [ ] **Создание MCP Server (Model Context Protocol):** Разработка локального MCP-сервера, предоставляющего безопасный доступ к базе бюджета. Это позволит подключать к базе внешние AI-ассистенты (например, десктопного Claude или AI-IDE) для глубокого анализа всей финансовой истории.
- [ ] Продвинутый экспорт (CSV/Excel) по естественному запросу ("Выгрузи мне все траты на машину за год в эксель").
